# آزمون خودکار تمرین ۲ (فرایندها)

این پوشه شامل آزمون‌های خودکار تمرین ۲ است. بعد از اتمام کار، از ریشه
مخزن xv6 (جایی که فایل Makefile است) اجرا کنید:

```
python3 hw2-tests/grade-hw2.py
```

اسکریپت به صورت خودکار برنامه‌های آزمون (`t_pinfo` و `t_killtree`) را به
مخزن اضافه می‌کند، xv6 را می‌سازد، در QEMU بوت می‌کند و پنج بررسی را اجرا
می‌کند:

| بررسی | چه چیزی سنجیده می‌شود |
|---|---|
| pingpong | اجرای برنامه pingpong و فرمت خروجی |
| race | ترتیب خروج statusها باید 5، 4، 3، 2، 1 باشد |
| t_pinfo | صحت getpinfo: pid، ppid، نام، وضعیت و ترتیب age |
| t_killtree | killtree باید کل درخت (۵ فرایند) را از بین ببرد |
| ps | اجرای برنامه ps و فرمت جدول خروجی |

خروجی پایانی جدول امتیاز است (`score: 5/5`)؛ اسکریپت با امتیاز کامل
کد خروج ۰ و در غیر این صورت کد خروج ۱ برمی‌گرداند.

نکته: اسکریپت فایل‌های آزمون را در user/ کپی می‌کند و Makefile را تغییر
می‌دهد؛ این تغییرات را هنگام تحویل نگه دارید.
